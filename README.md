🛒 Simple Products Store – Training Project
This is a simple training project created at the beginning of the course after completing the fundamentals of JavaScript.
The project displays products fetched from a fake API and shows them inside a clean, basic HTML page styled with CSS.

📌 Features
Fetching product data from a fake API using fetch()

Displaying products dynamically inside the HTML page

Simple and clean UI built with CSS

Organized file structure (HTML, CSS, JS)

A beginner‑level project to practice JavaScript fundamentals

🧰 Technologies Used
HTML5

CSS3

JavaScript (ES6)

Fake Store API (or the API you used)
